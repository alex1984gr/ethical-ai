How have you used AI for coding so far?

Do you usually try problems yourself first?

First, I try to understand the problem and solve it on my own. Then, afterwards, I ask the AI to give me improvements that I might not have thought of.

Can you explain code you've submitted without AI's help?

When the code is written by you, it is clearly much easier to explain it without the help of AI. But if the code is written by AI, then it becomes harder to understand and even harder to explain.

What would happen if AI was unavailable during an exam or job test?

In this case, I should rely on my own knowledge and my ability to solve problems without using technology.
